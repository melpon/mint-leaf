# hintxiv/mint-leaf に選択ジョブのパレット表示を追加する

- Polished: {YYYY-MM-DD}

## 目的

選択中ジョブに応じたスキルパレットを見やすく提示し、アクション選択の操作効率を上げる。

## 優先度根拠

編集体験の改善効果はあるが、既存 UI でも操作自体は可能であるため Medium とする。

## 現状

- スキル一覧は利用できるが、選択中ジョブとの対応が直感的でない場面がある
- fork 側ではパレット表示改善があるが、upstream 向けには独立した差分整理が必要

## 設計方針

- ジョブ選択の既存導線は維持し、視覚的なパレット表示を追加する
- 表示追加は最小限の状態変更で実装し、既存データ構造を壊さない
- 表示ロジックとデータ取得ロジックを分離する
- ジョブ別スキル一覧は localStorage に TTL キャッシュし、期限内は即表示する（期限切れは stale 表示＋手動再取得で更新する）

## 作業時の注意事項

- この issue は hintxiv/mint-leaf への PR を前提とし、upstream の実装方針と命名を尊重すること
- コミットメッセージ、PR 本文、コードレビュー上のコメントは英語で記載すること
- 既存機能（エクスポート、編集、並び替え、既存保存データ読込）を壊さないこと
- 作業は `_working/mint-leaf` 配下で `main` からブランチを切って行うこと

## スコープ外

- ローテーション多段レイアウトの追加
- ローカル保存仕様の変更
- i18n の追加改修

## 完了条件

- 選択中ジョブのパレットが明確に表示される
- 既存のアクション追加・編集フローに回帰がない
- 既存のジョブ切替と API 取得動作が維持される
- キャッシュが有効な場合は即表示され、手動再取得で一覧が更新される

## 解決方法

1. `_working/mint-leaf` の `feature/add-selected-job-palette-view` で、選択ジョブの PvE スキルパレット（`JobActionList`）を Editor パレットに追加した
2. XIVAPI からジョブ技を全件取得し（`xivapiSearchAll`）、ロールアクションとホットバー非セットの置換スキルも含めた。`ClassJobCategory=1`（全クラス）の共有コンテンツは除外した
3. アイコンホバーでスキル説明ツールチップを表示し、一覧は localStorage の TTL キャッシュ（即表示／手動再取得）にした
4. 実装コミットは `99cbfef`。hintxiv 向け PR はこれから出す
