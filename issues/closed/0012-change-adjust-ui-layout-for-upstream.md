# hintxiv/mint-leaf 向けに UI レイアウト変更を取り込む

- Created: 2026-09-04
- Completed: 2026-09-04
- Model: GPT-5.6
- Branch: feature/change-adjust-ui-layout
- Polished: {YYYY-MM-DD}

## 目的

hintxiv/mint-leaf の既存体験を尊重したまま、作業効率が上がる UI レイアウト変更を段階的に取り込む。

## 優先度根拠

利用体験を改善する価値は高いが、機能追加ではなく既存機能でも利用は可能であるため Medium とする。

## 現状

- 画面構成は利用可能だが、複数領域を行き来する操作で視線移動が多い
- ローテーション編集と周辺操作の位置関係に改善余地がある
- fork 側ではレイアウト調整が入っているが、upstream 取り込み用の差分整理が必要

## 設計方針

- 既存コンポーネント構成を大きく壊さず、配置のみを中心に調整する
- 先に i18n 対応 PR を取り込めるよう、文言変更と構造変更を混在させない
- レイアウト変更と機能追加を分離し、レビュー可能な差分にする

## 作業時の注意事項

- この issue は hintxiv/mint-leaf への PR を前提とし、upstream の実装方針と命名を尊重すること
- コミットメッセージ、PR 本文、コードレビュー上のコメントは英語で記載すること
- 既存機能（エクスポート、編集、並び替え、既存保存データ読込）を壊さないこと
- 作業は `_working/mint-leaf` 配下で `main` からブランチを切って行うこと

## スコープ外

- ローテーション多段表示ロジックの追加
- 新しい保存仕様の導入
- 日本語翻訳文言の追加修正（i18n issue 側で実施）

## 完了条件

- レイアウト変更後も既存操作フローで編集とエクスポートが可能
- 主要画面で崩れがない
- 既存ショートフロー（新規作成、編集、出力）に回帰がない

## 解決方法

1. `_working/mint-leaf` の `feature/change-adjust-ui-layout` で、縦積み（Header / Abilities / Canvas / Footer）から編集ペインとプレビューを横に並べる画面構成へ変更した
2. ローテーション編集の主体をテキスト入力から `Action[]`（リスト選択・詳細編集・DnD・Import/Export）へ移した
3. Canvas のプレビュー表示を追加した
4. 実装をコミット `4e4e1a2` にまとめ、`origin/main` を取り込んだうえで tip を `5961109` とした。hintxiv 向け PR はこれから出す
