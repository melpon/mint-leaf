# スキル回しを localStorage に保存し一覧とテキスト入出力を追加する

- Priority: High
- Created: 2026-09-03
- Completed: {YYYY-MM-DD}
- Model: Composer
- Branch: feature/add-named-rotation-library
- Polished: {YYYY-MM-DD}

## 目的

エディタ上のスキル回しは React state のみで、リロードやタブを閉じると消える。作品レコードの集合と `activeId` を localStorage に持ち、再訪時に同じレコードへ復帰できるようにする。同じストアを、左パネルから複数件見返し・開き直し・新規作成・削除できるようにする。別端末への退避や受け渡しは、共有 URL ではなく **レコード一式のテキストをコピー / 貼り付け** で行う。

## 優先度根拠

リロードで作業が消えるのは日常利用の障害である。一覧・新規・削除・テキスト入出力も同じストアの上に載るため、永続化だけを先行させる役割は残らず、本 issue でまとめて扱う。High とする。

## 現状

- エディタ状態は `src/components/Home.tsx` の `useState` のみ（`job` / `rotationTitle` / `expansion` / `patch` / `level` / `prepullRotation` / `rotation` / `wrapWidth` / `rowSpacing`）
- 初期値は毎回デフォルト（ジョブ `DRK`、空シーケンス、`en` / `ja` の `defaults`）
- localStorage は別用途のみ
  - `src/lib/customActionsStore.ts`（`mint-leaf-custom-actions`）
  - `src/lib/jobActionsStore.ts`（`mint-leaf-job-actions`）
  - `src/context/LanguageContext.tsx`（`mint-leaf-locale`）
- 新規作成・作品一覧の UI は無い。`TopBar` の主操作は PNG エクスポートのみ（`src/components/TopBar/TopBar.tsx`）
- `Home` は Client Component。マウント前に `localStorage` を読むと SSR / ハイドレーションと食い違う
- テキスト入出力は Editor パネルのシーケンス専用（`src/components/Editor/ImportExport.tsx` + `src/lib/parseRotation.ts`）であり、ジョブ・タイトル・パッチ・折り返しなどは含まれない。本 issue の入出力とは別物であり、置き換えない
- 画面は TopBar → MetaBar → 左エディタ 3 列（パレット 280px + シーケンス 320px + 詳細 300px）＋ Canvas。常設の 4 列目を足す余地は小さい

## 設計方針

作成中の保存は独立した下書きスロットではなく、**作品レコードの集合 + いま編集中の ID** とする。一覧・新規・削除・テキスト入出力も同じストアを使う。

### 永続化

- ストレージは作品レコードの辞書と `activeId` を 1 キーで持つ（キー名は既存の `mint-leaf-*` に合わせる。キャッシュキーとは別にする）
- 各レコードはエディタが再現できる一式を持つ
  - `id`
  - タイトル（MetaBar の Rotation Title）
  - ジョブ（`jobs` のキーである略称）
  - `expansion` / `patch` / `level`
  - `wrapWidth` / `rowSpacing`
  - `prepullRotation` / `rotation`（`Action` は JSON 可能な形。`imageSrc` は文字列）
- `activeId` が「いま編集中のレコード」を指す。エディタの変更はアクティブなレコードへ書き戻す
- 初回（レコードが無い）は空のレコードを 1 件作って `activeId` にする
- 起動時は `activeId` のレコードで `Home` の state を復元する。不明なジョブ略称は既存どおり `DRK` に落とす
- 破損・パース失敗時は空のレコードを作り直して続行する（アプリを壊さない）
- 復元はマウント後（`useEffect`）で行い、SSR との不一致を避ける
- 書き込み失敗（容量超過など）は既存ストアと同様に握りつぶさず、ログは英語で残す。UI 通知の詳細は実装時に最小でよい

### UI

モーダルにはしない。モーダルは一覧と「いま編集中の回し」の空間的な関係が切れる。代わりに、画面左端から引き出すフローティングパネルにする。

- 画面左端（TopBar / MetaBar の下）に、畳んだ状態でも見える出っ張り（タブ）を置く
- タブを選ぶと左からフローティングパネルが開く。もう一度タブを選ぶ、またはパネル外をクリックすると畳む
- パネルはレイアウトを押し広げない。パレット列の上に重ね、Canvas は隠さない。幅はパレット列と同程度（おおむね 240–280px）
- 作品の寿命操作（新規作成・削除・切替・テキスト入出力）はすべてこのパネルに置く。TopBar に新規作成や「一覧」は置かない。TopBar は PNG エクスポートなどキャンバス操作に徹する
- MetaBar のタイトル欄は「いま開いている作品の名前」の編集のままにする。タイトル欄を作品切替用のセレクトにはしない

### 一覧

- 各行の表示は **ジョブ + ローテーション名** とする。ジョブ名はロケールに合わせる（`getJobName`）。ローテーション名は MetaBar の Rotation Title。別ダイアログの「名前を付けて保存」は置かない
- ジョブアイコンを名前の左に置いてよい
- アクティブなレコードは一覧上で明示する
- 行を選ぶとロードする。切替前に、いまのアクティブなレコードへ現在の編集内容を書き戻す

### 新規作成・削除

- 新規作成はパネル内から行う。先にアクティブなレコードへ書き戻してから、デフォルトの新しいレコードを追加し `activeId` を切り替える
- 削除は各行から行う。誤操作防止のため確認を 1 段挟む
- アクティブなレコードを消した場合は、残件があればどれかをアクティブにし、無ければ空レコードを 1 件作る

### テキスト入出力

- テキストエクスポートは各行から、対象レコードの **メタ + シーケンス一式** をクリップボードへコピーする
- テキストインポートはパネル内に置く。大きなテキストエリアは常時出さず、操作したときだけ出す
- インポートは貼り付けからレコードを復元し、**新しいレコードとして追加してアクティブにする**。既存レコードを黙って上書きしない
- テキスト形式は実装で決めてよいが、メタ無しのシーケンス専用テキストと混同しないこと。パース失敗はエラーとして返し、エディタを壊さない

認証・共有 URL・公開ギャラリーは対象外。

### スコープ外

- Editor パネルのシーケンス専用 Import / Export の改修や削除
- 一覧用の常設サイドバー（レイアウトを押し広げる 4 列目）
- 共有 URL、ログイン、サーバ保存、ソーシャル
- カスタムアクションキャッシュやジョブアクションキャッシュの統合

## 完了条件

- リロード後も、直前まで編集していたスキル回し（メタ + シーケンス + 折り返し）が復元される
- ハイドレーションエラーを起こさない
- 左端の出っ張りからパネルを開閉できる。開いたとき Canvas は隠れず、閉じるとエディタ操作を妨げない
- 保存済みのスキル回しが一覧に **ジョブ + ローテーション名** で並び、アクティブな件が分かる
- 行を選んでエディタにロードできる。ロード後にリロードしても、そのレコードがアクティブのまま復元される
- パネル内から新規作成できる。それまでの内容はレコードとして残り、エディタは新しい空の回しになる
- パネル内から削除できる（確認あり）
- レコード一式をテキストとしてコピーでき、貼り付けで新しいレコードとして取り込める
- 不正なテキストを貼ってもアプリが壊れない
- シーケンス専用 Import / Export の既存動作を本 issue で変えない

## 解決方法

1. `src/lib/` に作品レコードと `activeId` の読み書きモジュールを追加する（`customActionsStore` と同系統）。列挙・新規・削除・インポート用の挿入を同じスキーマで持つ
2. `Home` でマウント後にアクティブなレコードを復元し、以降の編集をそのレコードへ書き戻す
3. 左端タブ + フローティングパネルの UI を追加する（`Home` 配下。Editor 3 列の内側には置かない）
4. パネルに一覧・新規・削除・テキスト入出力を実装する。ロード時はアクティブへの書き戻し → `activeId` 変更 → `Home` の state 反映、の順にする
5. レコード一式のテキスト化とパースを `src/lib/` に置く。シーケンス専用の `parseRotation.ts` を流用してメタを落とさない
6. 文言は `src/messages/en.ts` / `ja.ts` に追加する
7. リロード・開閉・一覧・ロード・新規・削除・コピー・貼り付け・不正テキスト・不正 JSON を手動確認する
