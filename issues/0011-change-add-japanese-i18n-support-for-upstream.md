## 目的

hintxiv/mint-leaf に対して、既存機能を壊さずに日本語 UI を追加し、英語 / 日本語を切り替えて利用できるようにする。

## 優先度根拠

fork 側で最も利用価値が高い変更であり、他の UI 変更や機能追加より先に upstream へ提案したい中核機能であるため High とする。

## 現状

- 言語切替の仕組み自体はあるが、upstream へ出す前提の粒度で整理されていない
- 既存文言の一部に直書きやキー整理不足があり、後続機能追加時に翻訳漏れが発生しやすい
- title や補助文言の扱いがコンポーネントごとに分散している

## 設計方針

- 既存の英語表示をデフォルトとして維持し、日本語表示を追加する
- 文言は `src/messages/en.ts` と `src/messages/ja.ts` で対になるように管理する
- 文言直書きを避け、可能な限り翻訳キー経由で表示する
- localStorage の既存ロケールキー互換は維持する

## 作業時の注意事項

- この issue は hintxiv/mint-leaf への PR を前提とし、upstream の実装方針と命名を尊重すること
- コミットメッセージ、PR 本文、コードレビュー上のコメントは英語で記載すること
- 既存機能（エクスポート、編集、並び替え、既存保存データ読込）を壊さないこと
- ローテーションのテキスト入出力（import / export）は言語選択に応じて正しく動作することを確認する（`src/lib/parseRotation.ts` の整合）
- 作業は `_working/mint-leaf` 配下で `main` からブランチを切って行うこと

## スコープ外

- レイアウト改修
- ローテーション多段表示
- 選択ジョブのパレット表示改善
- 複数ローテーション保存機能の仕様変更

## 完了条件

- 英語 / 日本語を UI 上で切り替えできる
- 主要 UI 文言が翻訳キー経由で表示される
- 英語表示の既存挙動が回帰していない
- ローテーション import / export と編集フローが、言語切替後も回帰しないこと
- 言語設定が再訪時にも維持される

## 解決方法

1. 既存文言のキー整理と翻訳キー参照の統一を行う
2. 英語 / 日本語の文言セットを対で整備する
3. タイトルを含む主要表示の切替挙動を統一する
4. 既存機能の回帰を手動で確認する
